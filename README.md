# PROJECT : LOGIC

## 1. 프로젝트 소개

**PROJECT : LOGIC**은 플레이어가 제한된 공간에서 단서를 수집하고 논리적 추론을 통해 퍼즐을 해결하는 스토리 기반 방탈출 게임이다.

게임은 인공지능 안내 시스템인 'ECHO(에코)'의 지시에 따라 진행된다. 플레이어는 각 스테이지에 배치된 단말기와 기록을 조사하고, 수집한 정보를 분석하여 잠긴 출구를 개방해야 한다.

특히 게임이 진행될수록 안내 시스템이 제공하는 정보의 신뢰성이 달라지도록 구성하여, 플레이어가 주어진 정보를 무조건 수용하는 것이 아니라 스스로 판단하고 검증하도록 기획하였다.

Python과 Streamlit을 활용하여 웹 환경에서 실행할 수 있도록 개발하였으며, 픽셀 아트 기반의 그래픽과 키보드 조작, 상호작용 기능을 적용하였다.

## 2. 프로그램 사용법

### 2.1. 게임 실행

1. Streamlit으로 배포된 웹페이지에 접속한다.
2. 타이틀 화면에서 `START` 버튼을 클릭한다.
3. `NEW GAME`을 선택하여 새로운 게임을 시작한다.
4. 튜토리얼에서 기본 조작 방법을 익힌 후 스테이지에 진입한다.
5. 주변 사물을 조사하고 단서를 조합하여 퍼즐을 해결한다.

타이틀 화면의 `HOW TO PLAY` 버튼을 통해 게임 조작 방법을 별도로 확인할 수 있다.

### 2.2. 기본 조작 방법

| 조작 | 기능 |
|---|---|
| W / A / S / D | 캐릭터 이동 |
| E | 사물과 상호작용 |
| Space | 대사 및 메시지 넘기기 |
| H | 도움말 확인 |
| I | 인벤토리 확인 |
| 일시정지 버튼 | 게임 일시정지 및 메뉴 표시 |

게임 내 상호작용이 가능한 사물에 접근하여 지정된 키를 입력하면 해당 사물의 정보를 확인하거나 퍼즐을 진행할 수 있다.

## 3. 주요 기능 설명

### 3.1. 타이틀 화면 및 게임 시작

- 게임 제목과 부제를 표시하고 시각적 효과를 적용한다.
- `START` 버튼을 통해 새로운 게임 시작 또는 이어하기 메뉴를 표시한다.
- `HOW TO PLAY` 버튼을 통해 조작 방법을 확인할 수 있다.
- 새로운 게임 시작 시 기존 플레이 기록의 존재 여부에 따라 확인 창을 표시하도록 설계하였다.

### 3.2. 캐릭터 이동 및 상호작용

- 키보드 입력을 통해 캐릭터를 상하좌우로 이동시킨다.
- 캐릭터가 특정 사물에 접근하면 상호작용할 수 있도록 구성한다.
- 카드키, 단말기, 노트, 보안 패널 등 사물의 종류에 따라 서로 다른 상호작용을 실행한다.
- 벽과 장애물을 고려하여 캐릭터의 이동 가능 범위를 제한한다.

### 3.3. 대사 및 스토리 진행

- 안내 시스템 ECHO의 대사를 통해 게임의 배경과 진행 상황을 전달한다.
- 플레이어의 입력에 따라 대사를 순차적으로 출력한다.
- 튜토리얼과 각 스테이지에서 동일한 방식의 메시지 시스템을 사용하도록 설계하였다.
- 스테이지가 진행될수록 ECHO가 제공하는 정보의 신뢰성이 변화하는 스토리를 기획하였다.

### 3.4. 아이템 및 인벤토리

- 플레이어가 특정 사물과 상호작용하면 아이템을 획득할 수 있다.
- 획득한 아이템을 인벤토리에 표시하도록 구성한다.
- 인벤토리 화면은 게임 화면 위에 별도의 창으로 표시되도록 설계하였다.
- 튜토리얼에서는 카드키를 획득하고 카드리더에 사용하는 과정을 통해 아이템 활용 방법을 학습한다.

### 3.5. 튜토리얼

- 게임 시작 전 기본적인 이동과 상호작용 방법을 안내한다.
- 카드키를 획득하고 카드리더를 작동시키는 간단한 퍼즐을 제공한다.
- 아이템 획득과 문 개방 과정에 시각적·청각적 효과를 적용한다.
- 튜토리얼을 완료하면 다음 스테이지로 이동하도록 구성한다.

### 3.6. Stage 01 — ARCHIVE ACCESS

- 기록 보관 구역을 배경으로 하는 첫 번째 스테이지이다.
- 제한 시간 12분 안에 단서를 수집하고 보안 장치를 해제하는 것을 목표로 한다.
- A, B, C 단말기를 조사하여 숫자 정보를 확인한다.
- 노트에 기록된 순서에 따라 단말기의 정보를 조합하여 비밀번호를 추론한다.
- 보안 패널에 비밀번호를 입력하면 정답 여부를 판별하고 출구 개방 상태를 변경하도록 설계하였다.
- 플레이할 때마다 비밀번호가 달라질 수 있도록 무작위 생성 기능을 적용하는 방향으로 개발하였다.

### 3.7. 게임 진행 관리

- 스테이지별 제한 시간을 표시하는 타이머 기능을 구성한다.
- 일시정지 메뉴에서 게임 재시작과 타이틀 화면 이동 기능을 제공하도록 설계하였다.
- 스테이지 완료 시 다음 화면으로 전환하는 기능을 구성한다.
- 플레이 기록을 이용한 이어하기 기능을 개발하고 있다.
